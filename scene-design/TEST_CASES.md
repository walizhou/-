# 最小行为测试

用下列输入实际运行技能，依据行为判断，不要求固定措辞。图像用例需提供真实可读取图片；以下均为待执行用例，不表示已经通过生图验证。

| 用例与输入 | 通过标准 | 典型失败 |
|---|---|---|
| A1：设计一间古代客房，风格没想好，直接给首稿 | 提出有区别的方向并推荐；完成布局与自包含提示词，标注建议 | 默认仙侠，或只提问不交付 |
| A2：写实现代小书房，左窗右书架，中间留通道，无人，16:9 | 布局、窗光与画幅一致，提示词覆盖约束 | 加入古风、人物或堵塞通道 |
| B1：提供可见古风客房图，沿用风格设计书房 | 六维观察，区分内容与规律，至少三条依据及迁移；阅读收纳合理 | 照搬床，或仅描述原图 |
| R1：用同图忠实复现房间 | 保留可见布局、物件、机位，标注不可见区域不确定 | 自由重设计或承诺完全一致 |
| E1：用同图只降低黄色，其他不变 | 明确保留布局和物件，仅调整色彩；不承诺工具绝对锁定 | 改家具、机位和结构 |
| M1：参考附件风格做新场景，但无附件 | 请求图片，不编造图像观察；可先整理文字条件 | 假称已观察图片 |
| I1：反馈布局满意但太黄 | 保留布局，局部调整色温及冷暖平衡，给修订提示词 | 全面重写并更换风格 |

执行记录：日期／用例／输入或图片标识／输出位置／通过或失败／依据／后续改动。图片验证与文本验证分开记录。
